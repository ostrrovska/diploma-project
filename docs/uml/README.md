# UML-модель прецедентів (StarUML)

Діаграма прецедентів Розділу 2 (підрозділ 2.6.1 у
[2_design.md](../2_design.md#use-cases)) будується в CASE-інструменті
StarUML за нотацією UML 2.5.

## Файли

- `use-case-model.mdj` — проєкт StarUML.
- `use-case-diagram.png` — експорт діаграми (File → Export Diagram As → PNG).

## Склад моделі

**Subject (System Boundary):** «B2C-підсистема маркетплейсу».

**Актори ліворуч (первинні):**

- Користувач (абстрактний, `isAbstract = true`);
- Покупець — Generalization → Користувач;
- Адміністратор платформи — Generalization → Користувач;
- B2B-система (Тема 2) — стереотип `«system»`;
- Планувальник — стереотип `«time»`.

**Актори праворуч (вторинні):** LiqPay, Expo Push / FCM (стереотип `«system»`).

## Побудова в StarUML

1. File → New; Model Explorer → Add Diagram → Use Case Diagram.
2. Розмістити Subject, підписати «B2C-підсистема маркетплейсу».
3. Додати акторів ліворуч і праворуч, прецеденти — всередині Subject.
4. З'єднати елементи інструментами Directed Association, Generalization,
   Include, Extend згідно з таблицями; для Extend задати Extension Point.
5. Зберегти проєкт як `use-case-model.mdj`, експортувати PNG як
   `use-case-diagram.png` у цю папку.
